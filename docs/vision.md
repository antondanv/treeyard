# Treeyard — видение

## Что и для кого

Дерево целей проекта в терминале. Корень — цель, которую видно в жизни; ветки — вехи
и направления; листья — задачи с критерием «готово, когда». Из любого узла открывается
сессия Claude Code, Codex, Antigravity или OpenCode, а агент пишет итог обратно в узел.

Для соло-разработчика, который ведёт несколько своих проектов с агентами.

## Зачем

Мои проекты раньше стартовали с 5–13 документов, код писался быстро, а потом проект вставал:
на шагах, которые может сделать только человек (сервер, домен, оплата, показать живому
человеку), пока агенты получали побочные фичи, а план разрастался в журнал на тысячи строк
(что из этого вынесено — [practice.ru.md](practice.ru.md)).

**Цель:** соло-разработчик ведёт свои проекты с агентами через дерево и доводит их до
проверки в жизни, а не до вечного «код готов, проект стоит».

## Веха 1 — сейчас

**2 недели веду свои проекты только через treeyard** — три проекта, включая сам Treeyard.
Сам своим инструментом улучшаю свою же разработку: всё, где treeyard мешает или чего не
хватает, записываю замечанием (`treeyard note`), лучшее становится узлами и делается.

Как поймём, что пройдена: 14 дней сессии по коду в трёх проектах открывались из узлов;
замечания записаны; главные исправлены; хотя бы один узел другого проекта прошёл через дерево
от начала до конца. Итог — в журнале узла «Итоги двух недель».

**Аппетит:** 2 недели, до 2026-10-16. Объём подстраивается под срок, а не наоборот.

## Веха 2 — потом

Знакомый ставит treeyard из npm и за 20 минут сам сажает дерево своего проекта. Для этого:
GitHub, Brainyard 0.2 на npm вместо `file:../Brainyard`, английский по умолчанию,
README на английском, чистый пакет, CI и публикация из релиза.

## Чего не делаем сейчас

- Не публикуем и не готовим к людям со стороны, пока не прожита веха 1.
- Не делаем фичи «заодно»: всплыло — замечание или узел-идея.

## Ограничения

- Node.js 22+, macOS — основная платформа; для панелей нужен tmux.
- Brainyard (`../Brainyard`) — единственный слой между treeyard и CLI агентов;
  пока он подключён из соседней папки, ставится только у автора.
- Живые проверки сессий — только на копии дерева, не на настоящих проектах.
