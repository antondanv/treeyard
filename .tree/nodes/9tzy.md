- 2026-10-02 22:15 · агент · Сделано (f1d37d9): treeyard note «…» [--node id] пишет идею в «Замечания» дерева из настройки notes (treeyard config notes <папка>), в описании «Откуда: проект › «узел» (id)». Узел берётся из --node, иначе из TREEYARD_NODE (его теперь получает каждая сессия из узла: терминал, панель, пробуждение), иначе по CLAUDE_CODE_SESSION_ID. Из обычного shell записывается только проект. Проверено: в Factoyard TREEYARD_NODE=e2ep treeyard note «проверка» → zdx7 в smug; дерево Factoyard не изменилось; панель на временном дереве получила TREEYARD_NODE; карточка видна в TUI на 130×36 и 100×30; typecheck, lint, 191 тест. Осталось: удалить zdx7 «проверка», когда посмотришь; идеи u4bc и 5348.
