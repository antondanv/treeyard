Сейчас экран панели читается опросом: 8 раз в секунду, а после клавиши или прокрутки сразу и затем каждые 16 мс полсекунды (узел «Задержка ввода и прокрутки в панели агента»). Вывод агента без ввода всё ещё ждёт до 125 мс, а простой стоит 6–8% CPU. Клиент tmux в control mode (-C) присылает %output при каждом изменении панели — тогда читать экран только по событию: ноль опросов в простое и вывод агента без задержки. Нужен API в Brainyard (watchPane или подобный), размер control-клиента не должен мешать resize-window.
