Учебный проект по Node.js (SourceCraft, k0709-24-1, ветка danilov-init): локальный веб-интерфейс для деревьев — просмотр и правка узлов, картинки, дифы, документы корня, история статусов, живое обновление, запуск агентов и терминал в браузере. Копия для быстрого чтения — SQLite. Знания о формате и сессиях остаются в Treeyard, веб — внешняя программа поверх CLI.

## Журнал

- 2026-11-11 11:37 · агент · завёл узел
- 2026-11-11 11:55 · агент · Человек 11.11: база веба — SQLite, не PostgreSQL (локальный инструмент, история статусов уже есть в узлах Treeyard); без ИИ и без ссылок для других; через веб — создание и правка узлов, картинки, дифы, документы корня — только командами treeyard. Узлы ветки описывают, чего для этого не хватает в CLI.
